# PeerSpace

A community-driven social platform built for **peers to help peers**.

## Overview

**PeerSpace** is a social platform designed around collaborative learning and knowledge sharing. Similar in spirit to platforms like Stack Overflow, PeerSpace allows users to ask questions, share knowledge, and help each other solve problems in a structured and interactive way.

The platform combines **community discussion, real-time interaction, and credibility-based reputation** to create an environment where useful contributions are recognized and rewarded.

## Features

### Community Posts

Users can create different types of posts such as:

* Questions
* Polls
* Guides
* Discussions

This allows communities to share knowledge, gather opinions, and discuss topics together.

### Answer-Based Discussions

Questions can receive multiple responses from the community. The original poster can **mark a comment as the accepted answer**, helping future readers quickly find the best solution.

### Voice Chat on Posts

Unlike traditional forums, PeerSpace allows **voice chat directly within posts**, enabling real-time discussion and collaboration between users. (This is still in testing, bugs are expected and loads aren't tested)

### Credibility System

Users can earn **credibility points** by helping others, answering questions, and contributing useful content. This encourages high-quality responses and recognizes helpful members of the community.

### Friends & Communication

Users can add friends and communicate with other members, making it easier to collaborate, discuss topics, and stay connected within the community.

### Communities

The platform is designed specifically for **peer-to-peer interaction**, allowing people with similar interests, studies, or expertise to help each other grow using widely known community feature like social media's.

## Goal

PeerSpace aims to create a space where **people can learn from each other, ask questions freely, and build credibility through meaningful contributions to the community**.
